# MCP for your AI agent

Repowise exposes its codebase tools over MCP so AI agents in your editor can ask
the index for grounded answers instead of guessing from open files. The MCP
server runs straight from the CLI, so it works whether or not the local server
is running.

VS Code agent mode picks it up on install. For other editors, run **Repowise:
Configure MCP for this Workspace** to register the Repowise MCP server for the
current repository.
