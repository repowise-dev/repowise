# See your first insight

Once the index is connected, open a file to see its health findings inline, or
open the **Home** view in the Repowise sidebar for the repository overview.

Run **Repowise: Open Code Health** to see the health map, the hotspots that
drive most of the risk, and the files worth refactoring first.

For the bigger picture, run `repowise serve` in a terminal. After a first index
the dashboard starts with a short guided tour of what stood out in your repo,
and Setup is where you connect agents, turn on sync and add coverage or a model.
