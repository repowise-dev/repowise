# Connect the server

The extension reads your index through a local server. Run **Repowise: Start
Server** to launch it for this workspace, or answer **Start** when the
extension asks.

The extension discovers the server from the lockfile it writes under `.repowise/`
and shows the connection state in the status bar. Click that item to stop or
restart the server whenever you want its memory back; a server the extension
started stops when you close the window. Your AI agent's MCP tools do not need
it.
