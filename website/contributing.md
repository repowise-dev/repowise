# Contributing

Contributions are welcome. The full guide is maintained in the repository and is the
single source of truth for setup, the development workflow and how to claim an issue.

**[Read CONTRIBUTING.md on GitHub →](https://github.com/repowise-dev/repowise/blob/main/.github/CONTRIBUTING.md)**

Setup commands are deliberately not repeated on this page. They changed often enough
that the copy here drifted from the real ones, and a wrong command costs more than a
second click.

## Quick links

- [Open an issue](https://github.com/repowise-dev/repowise/issues) — bugs, feature requests, questions
- [Open a pull request](https://github.com/repowise-dev/repowise/pulls)
- [Good first issues](https://github.com/repowise-dev/repowise/labels/good%20first%20issue) — reserved for first-time contributors
- [Help wanted](https://github.com/repowise-dev/repowise/labels/help%20wanted) — scoped work for people who know the codebase
- [Architecture guide](https://github.com/repowise-dev/repowise/blob/main/docs/architecture/README.md)

## Security issues

For security vulnerabilities, see
[SECURITY.md](https://github.com/repowise-dev/repowise/blob/main/.github/SECURITY.md).
Please do not open a public issue.
